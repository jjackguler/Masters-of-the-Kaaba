## 3. Build instructions

```
python build.py
```
(On Windows, `py build.py` also works; Python 3.8+ is enough, no external package.)

Outputs:
- `bekke-kabe.html` and `dist/web/kabe-ustalari.html`: web.
- `dist/app/www/`: offline app. Copy it into the Capacitor project's `www/` folder, then run `npx cap sync`.
- `dist/BUILD_MANIFEST.json`: hashes of every input and output.
